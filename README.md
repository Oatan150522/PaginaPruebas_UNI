
# Testing Web

## Descripción
Desarrollar una página web básica de pruebas utilizando únicamente HTML5 y CSS3.

El propósito es contar con una interfaz web sencilla que permita realizar pruebas de diseño, estructura visual y presentación de información.

## Tecnologías
- HTML5
- CSS3

## Estructura del proyecto

```text
testing-web/
│
├── index.html
├── css/
│   └── styles.css
└── README.md
```

## Requerimientos

- Crear una página web sencilla y funcional visualmente.
- Implementar un diseño limpio y organizado.
- Utilizar CSS para los estilos y la presentación.
- Crear una interfaz adaptable a diferentes tamaños de pantalla.
- Separar el código HTML de los estilos CSS.

## Ejecución

Abrir el archivo `index.html` directamente desde el navegador.

## Alcance

Este proyecto será únicamente una página web estática de pruebas. No requiere backend, bases de datos, APIs ni dependencias externas.
